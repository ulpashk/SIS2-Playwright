# SIS 2 — Test Automation with Playwright

## Project Description

The purpose of this project is to automate several main user flows of the Practice Software Testing website using Playwright and TypeScript.

Website under test: Practice Software Testing.

The automated tests will be independent and will use Page Object Model, fixtures, and unique test data where required.

## Test Cases to Be Automated

1. Register a new customer  
   Verify that a new user can create an account using unique registration data.

2. Log in  
   Verify that valid credentials open the account page and invalid credentials show an error.

3. Buy a product  
   Verify that a product can be added to the cart with the correct item and quantity and that checkout can be completed.

4. Compare two products  
   Open two products, capture their names and prices, and verify the comparison.

5. Reset a password  
   Verify the forgot-password flow for a known email and an invalid email.
